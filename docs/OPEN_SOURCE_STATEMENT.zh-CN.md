## F5-TTS：自行安装的外部工具

- 分别披露代码和权重：记录的 F5 SDK 采用 MIT；记录的官方 `F5TTS_v1_Base`
  权重采用 CC-BY-NC-4.0。具体代码提交、模型文件、revision 和许可链接见
  [第三方声明](../third_party/NOTICE.md#recorded-f5-source-and-model)，不据此推断
  所有 F5 衍生模型或辅助组件采用相同许可，也不证明远程服务实际加载了该版本。
- F5-TTS 不是控制器安装依赖，不随控制器、源码包或 wheel 获取或分发。
  X·Edit 的部署脚本不下载其 SDK/权重，不安装或启动其推理进程。
- 保留文字修改等必要能力的外部接口。默认不调用；需要该能力且未完成配置时，
  返回“请自行下载并安装F5-TTS”，而非自动安装或调用默认本地服务。
- 使用者应在仓库外自行取得、安装并部署兼容服务，核对许可后显式配置并启用。
  X·Edit 调用独立部署的编辑流水线，由该流水线使用用户配置的 F5 服务。
- 安装、启用或改为 HTTP 调用都不构成商业授权。F5 的代码许可与权重许可分别
  审查；所选权重的非商用限制不会被框架的 Apache-2.0 覆盖。商业场景应先取得
  权利人所需授权，不能仅凭本项目许可证使用受限权重。

F5 仍是相关编辑能力的外部运行前提，必须如实披露，不能表述为“完全无依赖”
或“无需遵守上游许可”。具体流程见 [外部工具说明](EXTERNAL_TOOLS.md)。

## dots.tts.edit 模型与管线选择

默认通过原创 HTTP 适配器调用用户独立部署的 dots.tts.edit 模型，支持文字、情绪、
音高/语速和停顿编辑；仍可显式选择原 edit-data-pipeline。保持工具输入一致，
不自动下载模型或 F5，不在模型失败时静默切回管线。其代码、权重和生成音频均
不属于本次分发对象。模型与代码的精确版本、许可证据和元数据差异详见
[部署与许可说明](DOTS_TTS_EDIT.md)；不将框架的 Apache-2.0 作为模型商用授权。

## 分发与审批边界

- Apache-2.0 允许自有框架按其条款使用，不意味着所有可连接的外部模型均可商用。
  “外部服务”“Git submodule”“用户自行下载”均不豁免上游条款。
- FFmpeg 的可选构建配方禁用 GPL、nonfree 和 version3 功能。若今后发布二进制或
  镜像，仍须逐一检查最终产物，包括基础镜像或软件包额外带入的 FFmpeg，并履行
  相应许可证义务；本次源码检查不代替完整镜像审计。
- 源码/包内容检查和接口回归只能证明相应技术边界，不能证明法律批准、完整商业
  可用性、模型质量或与历史 benchmark 一致。本轮未重新进行 GPU 推理验证。
- 当前源码已移除的内容可能仍存在于 Git 历史中。对外发布优先使用审核后的源码
  归档；如公开 Git 历史，必须另行审查，不能以当前文件删除代替历史清理。

审批材料应分别列出“自有开源对象”“启用后需要的外部运行工具”和“仅供参考的
用户扩展候选项”，不得将后两者统一重新授权为 Apache-2.0。具体许可证据见
[LICENSES.md](LICENSES.md)；未确认的许可和完整推理栈风险继续保留待审状态。
