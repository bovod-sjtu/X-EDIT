# Framework figure

`framework.png` is a PNG export of `figures/overview.pdf` from the accompanying
X·Edit manuscript, revision `8ad2529`. The diagram is unchanged; only its file
format was converted for GitHub display.

It illustrates perception, optional reasoning, planning, execution, reward
estimation, and revision. The example inside the figure is illustrative, not a
new measured benchmark result. No model weights, recordings, or generated audio
are embedded in this documentation asset.
